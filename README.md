# Final Fantasy VII Projects

Tools, research, and resources for Final Fantasy VII and related games. The
[homepage](https://ff7man.github.io/) has the full directory.

## FF7 Chocobo Tools

| Tool | Platform | What it does | Link |
| --- | --- | --- | --- |
| Classic Betting Calculator | Web | Enter race details to review possible bets. | [Open calculator](https://ff7man.github.io/calc.html) |
| RNG Tool | Web | Explore the original Chocobo racing RNG tool. | [Open RNG tool](https://ff7man.github.io/rng.html) |
| Manual Race Tool | Web | Enter six chocobos' stats and jockey colors by hand; see suggested bets. | [Open manual tool](https://ff7man.github.io/manual/) |
| PC Race Predictor | Web | Predict PC-version chocobo stats and prizes from a time-based seed. | [Open PC predictor](https://ff7man.github.io/pc/) |
| PSX Frame Finder | Web | Find a PlayStation frame from the chocobo stats and prizes shown in game. | [Open PSX finder](https://ff7man.github.io/psx/) |
| PSX Computed Winner Lookup | Web | Find matching frames and use recorded winners where available; the prize hunt uses best guesses outside current coverage. | [Open PSX Computed](https://ff7man.github.io/psxcomputed/) |
| PSX Racer | Local emulator | Run a matched race in DuckStation and return the actual winners. | [Setup and source](https://github.com/ff7man/chocobo-betting/tree/main/psxracer) |
| PSX Data Generator | Local emulator | Farm PlayStation race results to extend PSX Computed. | [Setup and source](https://github.com/ff7man/chocobo-betting/tree/main/psxdatagen) |
| Frame Race Prototype | Local emulator | Buildable DuckStation patch for target-frame race testing. | [Setup and source](https://github.com/ff7man/chocobo-betting/tree/main/frame_race_prototype) |
